# ATDA Security Disclosure Policy

This repository contains a public **reference** model and architecture. It is not certified for CBRN interdiction, law enforcement use, payment processing or critical infrastructure production.

**Never submit** actual personal identifiers, payment data, sensor calibration secrets, detailed security bypass recipes, active device credentials, signing keys, site deployment secrets or live incident records to public issues. Use a controlled private disclosure channel with the owner/security lead. No secure reporting inbox is published here because its ownership and availability have not been verified.

Report privacy violations involving interaction-token reuse, payload k-gate breaches, token leakage, or cross-path data flow as critical. The software schema checks do NOT substitute for hardware PII stripping, encryption validation, attestation or independent risk review. The code's randomness, hard-k/DP privacy tension, timing side-channel and lack of production timing guarantees are explicitly documented.
